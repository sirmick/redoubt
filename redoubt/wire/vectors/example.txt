#   ok  HANDLES W0 W1 W2 W3 BUFFER NAME FIELD=VALUE...
#       decodes to exactly these fields, and re-encodes to the same words and (for a buffer
#       message) the first W1 bytes of BUFFER.
#   bad HANDLES W0 W1 W2 W3 BUFFER ERROR
#       is refused; ERROR is the Rust codec's `Error` variant (the Elixir codec only has to
