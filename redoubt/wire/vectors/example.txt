# Test vectors for the `example` protocol (redoubt/wire/tables/example.md), run by the Rust
# codec (redoubt/wire/tests/vectors.rs) and by the generated Elixir codec on beamlet
# (redoubt/wire/elixir/test/vectors_test.ex, via redoubt/wire/elixir/run-vectors).
#
#   ok       HANDLES W0 W1 W2 W3 BUFFER NAME FIELD=VALUE...     a request
#   bad      HANDLES W0 W1 W2 W3 BUFFER ERROR
#   reply    OP HANDLES W0 W1 W2 W3 BUFFER NAME FIELD=VALUE...  the reply to request OP
#   failed   OP HANDLES W0 W1 W2 W3 BUFFER ERROR-NAME           an error reply
#   badreply OP HANDLES W0 W1 W2 W3 BUFFER ERROR
#   file     BYTES NAME FIELD=VALUE...                          a request written into a file
#   badfile  BYTES ERROR
#
# Accepted lines decode to exactly these fields and re-encode to the same words and (for a
# buffer message) the first W1 bytes of BUFFER, or the same file bytes. Refused lines end with
# the Rust codec's `Error` variant (the Elixir codec only has to refuse). HANDLES is decimal;
# OP, words, BUFFER and BYTES are hex (`-` for none). Field values: integers in decimal,
# strings `s:` and byte arrays `b:` followed by their bytes in hex.
