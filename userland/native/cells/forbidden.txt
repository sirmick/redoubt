# The characters no cell's symbol may hold, and the one exception: the table both decoders keep.
#
# `forbidden FIRST LAST  what`: a range of code points, in hex, that is never drawn as itself and
# never a symbol's, wherever it stands: the printer (Redoubt.Term.Text, control?/1) draws it as
# text (`^[`, `^?`, `<U+200B>`), and a symbol holding it is refused by the cells crate
# (src/lib.rs, forbidden), by Redoubt.Term.Cells and by the screen buffer's natives. The one
# exception is the zero-width joiner, U+200D, inside an emoji ZWJ sequence: between an element
# (a pictograph, alone or followed by U+FE0F or a skin tone modifier, U+1F3FB to U+1F3FF) and a
# pictograph, the grapheme is one symbol and draws as one.
#
# `pictographic FIRST LAST`: Extended_Pictographic, the 78 ranges of Unicode 16.0, as the pinned
# OTP's (28.5) unicode_util has them (gc_1's gc_ext_pict clauses; it also decides the shell's
# graphemes).
#
# Each decoder states both in its own code; its tests hold every code point to this file:
# cells::the_forbidden_characters_and_the_pictographs_are_the_shared_tables, and the shell's
# text_test.exs. The file changes only with both.
