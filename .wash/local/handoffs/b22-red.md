## Open notes the next shell work should meet
- Editor undo: bounded by lines crossed + div(bytes of cursor line, 16) per step, 1,000,000 total, 500 steps; the worst case is a measured 16 MiB for 500 edits on a 1 MiB line. Fine; keep the byte term if the Buffer changes.
- Paste guard (editor and fm): a guarded key asks when in a burst (queued behind, or within 300 ms of a key that was); the question stays deaf until 300 ms after the burst's last key (re-armed by each dropped key with keys queued). Residual, by design: a pause over 300 ms before a chunk whose first key is Enter answers. The 300 ms is between the editor's handling of keys, not arrival. Bracketed paste would close it properly; the page's Open item names that.
- Highlighting: scanner linear ({length, role} spans, one binary_part cut), 4 KiB cap per line via Syntax.line/3 and after_lines/3 only; marks every 128 lines, reset on undo/redo/replace_all. Any new scanning path must go through Syntax.line/3.
- View.runs walks only to the window's right edge now; View.column reads only graphemes before the column. A new drawing path must not walk whole lines.
- Styles: only theme roles (Theme.get guards three atoms); every text through Widgets.label -> Text.visible; the terminal model (test/support/terminal.exs) raises on any non-encoder sequence, so every drawing test is an injection test. Keep hostile-line tests (escapes, bidi, NUL, combining, wide) for anything that draws file or user text.
- fm: operations only on the pane's own dir + a listed ok: true name through Files; `..` via Path.dirname; the confirm id fixes {action, from, name, to}; mkdir takes a typed name that Files refuses when bad. A name with control characters is ok: true (only /, NUL, ., .. are refused) and is navigable: titles and labels must stay visible-text (they are).
- Registry/index: commands load on first call via the build-time Redoubt.Commandlet.Index (SHELL7); the registry's Widget prefix skip is gone with it. Anything new that must be at the prompt costs footprint: check with beamlet-footprint.
- For the On-Redoubt steps (CONS1/RCMD1, native programs' screens): the strict list applies (consoled, the encoder, the session's authority); a native program's frames go through the one decoder; Ctrl+\ (0x1C) is the session's key found before decoding and no screen may take it (SHELL10); Ctrl+C is a key only for a screen started with ctrl_c: :key. Attack those: a frame or a key sequence that smuggles 0x1C, a paste through a native screen, a native program's text reaching the terminal without Text.visible.
